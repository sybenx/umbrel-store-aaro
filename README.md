# aaro app store

An Umbrel community app store. Add it in umbrelOS under App Store, then Community App Stores, with:

```
https://github.com/sybenx/umbrel-store-aaro
```

## Apps

- **Updates** (`aaro-updates`): one page to see and apply updates across your machines, Dockge stacks and Umbrels. Source: [sybenx/fleet-updates](https://github.com/sybenx/fleet-updates).
- **Miniflux** (`aaro-miniflux`): the Miniflux feed reader. A daily GitHub Action moves it to each new Miniflux release two days after it ships.

`templates/shortcut` is a template for a home screen icon that points at something already running, such as a Dockge stack.
